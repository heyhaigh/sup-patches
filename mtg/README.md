# MTG

Magic: The Gathering deck builder, Scryfall search, and match scaffolding for SupChat.

**Features:**
- Deck library with per-user persistence
- Scryfall card search and bulk lookup with 7-day global cache
- Quickstart deck builders for Standard (mono-color) and Commander (popular + custom search)
- Deck validation: card count, legality, commander color identity, singleton rules
- Match creation with lobby, mulligan phase, and basic turn system
- Standard 1v1 vs another user or AI bot (easy/medium/hard)
- Commander multiplayer (2-5 players)
- Full HTML launch app with sidebar nav, deck builder, and game UI

**Input:** Launch app (no text/image input needed)
**Output:** Interactive HTML app
